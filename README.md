# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**. The project provides a clean and responsive interface where two players can play against each other directly in the browser.

## 🚀 Features

* 🎯 Two-player Tic-Tac-Toe gameplay
* 🖱️ Interactive game board
* 🏆 Automatic winner detection
* 🤝 Draw/tie detection
* 🔄 Restart / New Game functionality
* 📱 Responsive design
* 🎨 Clean and simple user interface
* ⚡ No backend required

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Game logic, player turns, winner detection, and interactions

## 🎮 How to Play

1. Open `index.html` in any modern web browser.
2. Player 1 plays with **X**.
3. Player 2 plays with **O**.
4. Players take turns selecting empty cells.
5. The first player to get three symbols in a row wins.
6. If all cells are filled without a winner, the game ends in a draw.
7. Click the **Restart/New Game** button to play again.

## 🧠 Game Logic

The JavaScript implementation handles:

* Player turn management
* Cell selection
* Winning combinations
* Draw detection
* Game state management
* Restarting the game

The game checks all possible winning combinations after each move to determine whether a player has won.
